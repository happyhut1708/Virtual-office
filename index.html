        Deploy kit — GitHub + Vercel

        Halaman ini satu file index.html mandiri — tanpa build step, tanpa backend. Download paketnya, upload ke GitHub, deploy ke Vercel, jadi link publik yang bisa dibagikan ke siapa pun.

        1. Di github.com → New repository → nama virtual-office-showcase → Public → Create.
        2. Upload index.html + README.md hasil download di atas (tombol Add file → Upload files), lalu Commit.
        3. Paste deskripsi repo dari tombol copy ke kolom About di repo (ikon gear).
        4. Di vercel.com → Add New → Project → pilih repo tadi → Deploy. Link publiknya jadi virtual-office-showcase.vercel.app.
        Deskripsi repo GitHub Virtual Office Showcase — kantor pixel-art top-down berisi 9 bot AI dengan sprite hidup (kerja = ngetik, nyantai = Zzz, terjadwal = jam), panel agen, token usage, routing plan & aturan tim. Satu file HTML statis, data demo, siap deploy ke Vercel.
