        Deploy kit — GitHub + Vercel

        Halaman ini satu file index.html mandiri — tanpa build step, tanpa backend (scene 3D memuat library Three.js dari CDN, jadi perlu koneksi internet saat dibuka). Download paketnya, upload ke GitHub, deploy ke Vercel, jadi link publik yang bisa dibagikan ke siapa pun.

        1. Di github.com → New repository → nama virtual-office-showcase → Public → Create.
        2. Upload index.html + README.md hasil download di atas (tombol Add file → Upload files), lalu Commit.
        3. Paste deskripsi repo dari tombol copy ke kolom About di repo (ikon gear).
        4. Di vercel.com → Add New → Project → pilih repo tadi → Deploy. Link publiknya jadi virtual-office-showcase.vercel.app.
        Deskripsi repo GitHub Virtual Office Showcase — kantor 3D satu lantai berisi 11 bot AI + ruang presiden Agent M, terbagi 4 zona divisi (Kreatif & Konten, Market & Crypto, Riset & Planning, Dev). Karakter 3D hidup mengikuti status (kerja = ngetik, nyantai = Zzz, terjadwal = jam), panel agen, token usage, routing plan & aturan tim. Satu file HTML statis + Three.js via CDN, data demo, siap deploy ke Vercel.
